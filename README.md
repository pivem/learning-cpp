# C++ 500 Exercises

A structured learning journey through C++, starting from absolute zero
on September 23, 2026, based on *C++: 500+ Difficulty-Scaled Solved
Exercises* by George S. Tselikis.

## Goals

1. **Build a solid C++ foundation from the ground up**, progressing
   from basic syntax to advanced concepts through hands-on practice.
2. **Deepen my understanding of machine learning** by working in a
   lower-level language, where memory, performance, and data
   structures are explicit rather than abstracted away.
3. **Apply these skills to the global energy sector**, with a focus
   on power systems and regulatory analysis.

## Structure

Each chapter has its own folder, with one file per exercise.
